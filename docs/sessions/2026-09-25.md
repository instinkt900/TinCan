## Assumptions

T-034

T-036
- Screen activation and exit are handled in `SystemWorldBounds`, which has the
  world size, through a new `ComponentScreenExit`.
- An expired lifetime marks the entity dead instead of removing it directly, so
  its sections go with it in the same pass.
- The lifetime pass skips entities already marked dead, so a kill in the frame
  the lifetime runs out still counts as a kill.

T-038
- The loop state is stored as an index, `loop_from`, -1 for none.
- A pass that uses no time waits for the next update.
- The editor draws repeats only for spawn-relative behaviours whose pass starts
  and ends on a path; the approach from one pass into the next is not drawn.

T-027

  a `DataRef`.
- Pieces join every group the parent was in.

  ticks as their velocity.
