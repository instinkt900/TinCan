## Needs attention

- **Most of M1 is checked only by reading the code.** The launch check starts
  the game and closes it after a few seconds without input, so it never fires,
  dies, collects a pickup or reaches a game over. Two paths were exercised with
  temporary changes that were reverted before committing: the game over
  overlay (lives set to 1, 45 s run: it showed, and the fade ended 2.0 s later)
  and the test map (made the default, 30 s run). Everything else needs the
  manual steps, starting with T-050's test map.
- **Shutdown wait added in `GameLayer` (T-047).** Removing `GameLayer`'s debug
  font made every launch check fail with Vulkan validation errors on shutdown:
  textures, buffers and the frame's command buffer were destroyed while the
  last frame was still in use. The font's texture had been waiting for the GPU
  as it was destroyed. `GameLayer`'s destructor now calls
  `IGraphics::WaitIdle()`, as moth_toolkit's `Game` does. This is the same
  family as the two allowed shutdown VUIDs (moth_toolkit T-002).
- **Data files on the profile's must-still-load list were changed**, each by
  adding or renaming entries, never by changing a format the code reads:
  - `weapon_database_player.json` and `pickup_database.json` (T-039, allowed
    by the task): new weapon and pickup names, and a `progressions` category.
  - `enemy_database.json` (T-044, T-049, allowed): `score` and `large`.
  - `weapon_database_enemy.json` (T-041): an optional `sound` on the two enemy
    weapons. T-041 did not name this file; the change was taken as allowed
    because it only adds an optional field and the task needs per-weapon
    sounds. Revert it if that is not wanted.
  - `assets/sprites/explosion_01.json` (T-048): two short clips added; the
    `explode` clip is untouched.
- **The test map was written by a script** (T-050), from the stars map. Saving
  it in Tiled will reformat it.
- **New Discovered items:** projectile kill bounds pass edges to `MakeRect`,
  which takes a width and height, so bullets are removed at the screen's right
  and bottom edges rather than 200 px past them; T-051 is partly stale, and
  `enemy_basic` (used by `desert.tmj`) is in neither the enemy database nor
  the Tiled enum.
- No NOLINT suppressions were added.
